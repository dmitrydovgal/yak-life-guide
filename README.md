# Як? — Життєвий гід (демо-прототип)

Клікабельний прототип українського сервісу, який пояснює, як вирішувати повсякденні питання. Чистий HTML/CSS/JS, без збірки.

- Локальний запуск: `python -m http.server 5173` і відкрити http://localhost:5173
- Дані життєвих подій: відкритий реєстр [Гід з державних послуг](https://guide.diia.gov.ua/) (CC BY 4.0), скорочено. Оновлення: `cd _build && python build.py` (потрібен `registry.json` з `/register/download/json/`).
- Усі матеріали демонстраційні й не є юридичною консультацією.
