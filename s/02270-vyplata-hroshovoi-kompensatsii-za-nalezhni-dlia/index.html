Соціальний захист

Виплата грошової компенсації за належні для отримання житлові приміщення для дітей-сиріт

Повна назва: Виплата грошової компенсації за належні для отримання житлові приміщення для дітей-сиріт та дітей, позбавлених батьківського піклування, осіб з їх числа

Виплата грошової компенсації за належні для отримання житлові приміщення для дітей-сиріт та дітей, позбавлених батьківського піклування, осіб з їх числа передбачається в порядку черговості за заявою особи, та подачею необхідних документів.

Що знадобиться

  • Заява про виплату грошової компенсаці
  • Копія документа, що посвідчує особу (наприклад, паспорта громадянина України)
  • Документи (або копія рішення про їх видачу), що підтверджують статус дитини-сироти, дитини, позбавленої батьківського піклування, особи з їх числа
  • Документи, відповідно до яких було поставлено особу на квартирний облік як дитину-сироту, дитину, позбавлену батьківського піклування, для осіб після 23 років
  • Копія довідки про взяття на облік внутрішньо переміщеної особи (у разі наявності)
  • Копія довідки про присвоєння реєстраційного номера облікової картки платника податків (копія паспорта громадянина України - для фізичної особи, яка через свої релігійні переконання відмовилася від прийняття реєстраційного номера облікової картки платника…

Як отримати послугу

  1. Перевірте, чи послуга підходить вам: для кого вона та де діє.
  2. Підготуйте документи за переліком вище (деякі потрібні лише в окремих випадках).
  3. Оберіть спосіб звернення: письмово, поштою (рекомендованим листом), особисто.
  4. Подайте заяву до: Виконавчі органи сільських, селищних, міських рад; Обласні, Київська та Севастопольська міська державна адміністрація.
  5. Дочекайтеся результату (строк: Звичайне надання: У місячний строк).

Куди звернутися

  • Виконавчі органи сільських, селищних, міських рад
  • Обласні, Київська та Севастопольська міська державна адміністрація

Що ви отримаєте

  • Виплата грошової компенсації за належні для отримання житлові приміщення
  • Відмова у виплаті грошової компенсації за належні для отримання житлові приміщення

Підстави для відмови

  • Виявлення невідповідності поданих документів вимогам законодавства
  • Неперебування особи на квартирному обліку
  • Прийняття рішення про втрату статусу дитини-сироти, дитини, позбавленої батьківського піклування
  • Подання не у повному обсязі встановленого переліку документів
