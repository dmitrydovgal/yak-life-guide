Соціальний захист

Санаторно-курортне лікування (путівки) громадянам, які постраждали внаслідок Чорнобильської катастрофи

Громадяни України, які потраждали внаслідок Чорнобильської катастрофи, мають право на санаторно-курортне лікування (путівку).

Детальніше про послугу

Послуга надається щорічно у межах бюджетних коштів для компенсації вартості путівок через безготівкове перерахування санаторно-курортним закладам відповідно до укладених договорів з урахуванням черговості подання заяв.

Де отримати
Особисто, поштою, електронною поштою: Виконавчі органи сільських, селищних, міських рад; ЦНАП

Безоплатно

Способи подачі: чим відрізняються

  • Особисто. Звернутися з документами: Виконавчі органи сільських, селищних, міських рад; ЦНАП. Перевага: Можна подати оригінали й поставити запитання на місці. Обмеження: Потрібно прийти в робочий час; можливі черги.
  • Поштою. Надіслати заяву та документи рекомендованим листом. Перевага: Без візиту в установу. Обмеження: Додатковий час на доставку листа.
  • Електронною поштою. Надіслати заяву електронною поштою органу. Перевага: Без візиту, швидке надсилання. Обмеження: Уточніть адресу та вимоги до файлів в органі.

Чек-лист документів

  • Для забезпечення громадянина, віднесеного до категорії 1: Заява про взяття на облік для отримання путівки за формою, затвердженою наказом від 21.04.2015 № 441 "Про затвердження форми Заяви про призначення усіх видів соціальної допомоги, компенсацій та пільг"; Довідка для одержання путівки на…Навіщо: Підтверджує відомості, потрібні для рішення органу.Форма: за встановленою формою
  • Для забезпечення дитини з інвалідністю та одного із батьків або особи, яка їх замінює: Заява; Довідка для одержання путівки на санаторно-курортне лікування за формою 070/о; Довідка для одержання путівки одним із батьків дитини з інвалідністю або особою, яка їх замінює, на санаторно-курортне…Навіщо: Підтверджує відомості, потрібні для рішення органу.Форма: за встановленою формою

Результат

Ви отримаєте: Взяття на облік для забезпечення санаторно-курортною путівкою. Строк: 10 днів (календарні). Отримати результат можна особисто, поштою (рекомендованим листом).

Якщо відмовили

Підстави для відмови за реєстром:

  • Подання документів до заяви не в повному обсязі.
  • Заява подана особою, яка не має права на взяття на облік для забезпечення санаторно-курортним лікуванням

Рішення можна оскаржити в суді.

Що далі: пов’язані послуги

  • Призначення грошової компенсації вартості самостійного санаторно-курортного лікування постраждалим
  • Видача посвідчень особам, які постраждали внаслідок чорнобильської катастрофи
  • Оформлення документів для включення до єдиного обласного банка даних дітей, які постраждали внаслідок…
  • Оформлення документів для включення до єдиного обласного банка даних осіб, які постраждалих внаслідок…
  • Довідка про заробітну плату, одержану за роботу в зоні відчуження в 1986-1990 роках
