Витяг з реєстру платників єдиного податку

Повна назва: Надання витягу з реєстру платників єдиного податку

Зареєстрований платник єдиного податку може безоплатно отримати від Державної податкової служби України витяг з реєстру платників єдиного податку. Витяг з реєстру платників єдиного податку підтверджує факт перебування суб'єкта господарювання на спрощеній системі оподаткування, обліку та звітності та обрані ним види господарської діяльності

Коротко
Строк надання
Для зареєстрованих платників єдиного податку: 1 день (робочі); Для суб’єктів господарювання, які подали заяву щодо переходу на спрощену систему оподаткування: 2 дні (робочі)
Вартість
Для зареєстрованих платників єдиного податку: Безоплатне надання; Для суб’єктів господарювання, які подали заяву щодо переходу на спрощену систему оподаткування: Безоплатне надання
Для кого
Юридична особа, Фізична особа-підприємець
Де діє
ВСЯ УКРАЇНА
Хто надає
Державна податкова служба України, ВСЯ УКРАЇНА

Як отримати послугу

  1. Перевірте, чи послуга підходить вам: для кого вона та де діє.
  2. Підготуйте документи за переліком вище (деякі потрібні лише в окремих випадках).
  3. Оберіть спосіб звернення: письмово, поштою (рекомендованим листом), особисто, online: https://cabinet.tax.gov.ua/login.
  4. Подайте заяву до: Головні управління Державної податкової служби України в областях та м. Києві; Міжрегіональні управління ДПС по роботі з великими платниками податків.
  5. Дочекайтеся результату (строк: Для зареєстрованих платників єдиного податку: 1 день (робочі); Для суб’єктів господарювання, які подали заяву щодо переходу на спрощену систему оподаткування: 2 дні (робочі)).

Куди звернутися

  • Головні управління Державної податкової служби України в областях та м. Києві
  • Міжрегіональні управління ДПС по роботі з великими платниками податків

Онлайн-сервіс: https://cabinet.tax.gov.ua/login
