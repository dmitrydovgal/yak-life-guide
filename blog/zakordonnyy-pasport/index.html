Як оформити закордонний паспорт

Опубліковано: 25 листопада 2026 · Посилання перевірено: 25 листопада 2026 · 3 хв читання

Коротко
  • Порядок залежить від того, чи це перше оформлення, обмін, документ для дитини або заміна втраченого паспорта.
  • Актуальну послугу, перелік документів, запис, вартість і строки перевіряйте на сайті ДМС.
  • Для дітей можуть діяти окремі вимоги щодо присутності та документів законних представників.
  • Не плануйте поїздку лише за приблизним строком виготовлення.

Порядок оформлення закордонного паспорта залежить від того, чи це перше оформлення, обмін, документ для дитини або заміна втраченого паспорта.

Перед поданням

  1. Знайдіть актуальну послугу на сайті ДМС.
  2. Перевірте перелік документів для своєї ситуації.
  3. Уточніть, чи потрібен попередній запис.
  4. Перевірте актуальну вартість і доступні строки.
  5. Після подання збережіть номер заяви або підтвердження.

Для дітей можуть діяти окремі вимоги щодо присутності та документів законних представників. Не плануйте поїздку лише за приблизним строком виготовлення: перевірте статус документа та чинні правила перетину кордону.
